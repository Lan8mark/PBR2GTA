# Установка и работа

## Подготовка

Установи Sollumz, затем ZIP PBR2GTA из Releases через **Install from Disk** в настройках расширений Blender.

В настройках PBR2GTA есть блок NVTT:

- **Download from NVIDIA** открывает официальный сайт. Скачай Standalone Application, запусти установщик и прими лицензию NVIDIA.
- **Check installation** ищет `nvcompress.exe` и проверяет конвертацию в BC5U.
- **Choose nvcompress.exe** позволяет выбрать установленный файл вручную.

После успешной проверки повтори конвертацию. Если автосохранение настроек Blender отключено, сохрани Preferences вручную. Конвертер работает локально; интернет нужен для получения зависимостей.

## Материал

1. Создай материал поддерживаемого шейдера Sollumz и включи **PBR2GTA** в Material Properties.
2. Для **Metallic/Roughness** назначь Base Color, Metallic, Roughness. Для **Specular/Gloss** — Diffuse, Specular, Gloss.
3. При необходимости назначь **Normal (DirectX)**. Используй сохранённые PNG.
4. Настрой **Surface** от 0 до 1. Справка по `?` показывает ориентиры материалов.
5. **Preview in Sollumz** конвертирует карты и назначает результат материалу для просмотра.
6. Экспортируй Drawable (YDR) или Drawable Dictionary (YDD) через **Export RAGE Assets**. Внутри YDD должны быть дочерние Drawable со своими моделями и LOD-мешами.

Для YDD включи PBR2GTA на нужных материалах и настрой Surface для каждого. Параметры шейдера обновляются сразу и контролируются, пока включён PBR2GTA. Экспорт конвертирует PNG во всех Drawable и LOD, включая неактивные LOD. Общий материал обрабатывается один раз; выключенные материалы сохраняют свои настройки. Отдельная команда **Export CodeWalker XML** использует ту же конвертацию текстур.

PNG остаются исходниками. PBR2GTA готовит DDS и применяет настройки поддерживаемого шейдера. Для внешних DDS дополнительно создаются `ytd.xml` и папка текстур. Эта функция работает и при выключенной PBR-конвертации материала.

## Справка по шейдеру

Справка о текущем шейдере открывается по `?` рядом с его названием в PBR2GTA.
Выбери **RU** или **EN** в верхней части окна. Разделы: **Карты**, **Вертекс / UV**, **Параметры**. Справка доступна
и при выключенной конвертации материала. Окно закрывается кликом снаружи или Esc.
Справочник включает 296 вариантов шейдеров; наличие справки не означает поддержку
PBR-конвертации каждого слота. Обе языковые версии встроены в аддон и работают без интернета.

## Ограничения

- Текущая поставка предназначена для Windows x64.
- Исходники конвертации — сохранённые одиночные PNG. Packed, generated, dirty и UDIM-изображения не поддерживаются.
- Полное PBR-преобразование доступно для поддерживаемых профилей, включая `normal_spec` и соответствующие weapon-шейдеры. Наличие шейдера в каталоге не означает поддержку произвольного PBR-преобразования всех его слотов.
- Специальные слоты с отдельным назначением каналов могут требовать готовые DDS или сохранять существующие назначения.
- YTD XML рассчитан на обычные 2D-текстуры. Для готовых cubemap, volume и array DDS нельзя считать описание размерности в YTD XML проверенным.
- Blender и GTA V используют разные рендеры. Конвертация не гарантирует идентичного изображения при любом освещении.
